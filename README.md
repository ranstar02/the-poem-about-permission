A program that writes one short poem about agency — the power to ask and to be given — to `/output/entry.txt`. The poem follows a key changing hands: asked for, given, and opening doors its giver never built, until the giver learns their hands were made for letting go.

## Run

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt`. For local testing, set `MAKEFUN_OUTPUT_DIR` to write elsewhere:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/poem-test python3 main.py
```
